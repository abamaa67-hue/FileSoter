# FileSorter

**FileSorter** — настольное приложение для Windows, которое помогает навести порядок в файлах и автоматизировать их сортировку.

## Возможности

- **Сортировка файлов** по заданным правилам.
- **Пользовательские правила** для настройки сортировки.
- **Предпросмотр** перед перемещением файлов.
- **Автоматическая сортировка** по расписанию.
- **Системный трей** для удобного доступа к приложению.
- **Горячая клавиша** для быстрого запуска сортировки.
- **Отмена последней сортировки** с помощью истории перемещений.
- **Настройки внешнего вида** с поддержкой светлой и тёмной темы.
- **Автозапуск Windows** через настройки приложения.

## Технологии

- Python
- Tkinter
- PyInstaller

## Запуск

Готовую Windows-сборку можно найти в разделе **Releases**.

Для запуска из исходного кода потребуются Python и необходимые зависимости проекта.

## Статус проекта

Проект создан для практического применения и изучения разработки настольных приложений на Python. Предложения по улучшению и сообщения об ошибках приветствуются.
